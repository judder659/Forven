# Forven 0.2.0 — the first stable release
#
# Hand-written notes for scripts/release.py (lines starting with # are ignored).
# Sections: New, Fixes, Safety; one "- " line per change, in plain words.

New:
- Updates now come as one tested release a week, with notes like these, instead of every change as it lands
- A new update experience: a badge in the top bar, a What's new panel, step-by-step progress with Retry, and a "You're on 0.2.0" card after the restart
- Choose Stable (weekly releases) or Latest (every change) in Settings > System > Updates
- Live probation: a strategy can trade real money at reduced size before going fully live, and probation is the only road from paper to live
- Multi-coin paper strategies: one strategy can paper-trade up to six coins, with results per coin
- Bot Factory: build, replay and paper-trade AI bots; Forven places their orders, so bots never hold exchange keys
- Paper strategies show the real check they are waiting on, with a "thin edge" tag when the backtest edge barely covers costs

Fixes:
- Restarts no longer lose agent tasks, gauntlet attempts or running bots
- Updates install new or changed Python packages and dashboard packages before restarting, so an update can't leave the dashboard broken
- Math library versions are capped to tested ranges, so a new numpy or pandas release can't break strategy creation
- Strategies another check still owns are no longer archived by mistake
- Slow agent strategies are no longer lost at registration

Safety:
- The dashboard only answers this computer by default, not other devices on your network
- Live strategies are judged on their own live trades, and their paused paper legs run to their exits
