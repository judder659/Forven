# Hand-written notes for scripts/release.py (lines starting with # are ignored).
# Sections: New, Fixes, Safety; one "- " line per change, in plain words.
# This file REPLACES the automatic notes for 0.5.0: add a line for every PR
# merged to main before the release runs (Monday 09:00 UTC).

New:
- Live strategies can now share coins. Any number of live strategies can trade the same coin, long or short, at the same time, instead of the first one blocking every other entry. Hyperliquid holds one position per coin (the sum of every strategy's trade) and Forven keeps each strategy's trade, stop, target and profit separately. See docs/live-netting.md
- The Live Trades page shows your slots at the top: how many live positions your balance can carry at once, how many are in use, and what each coin adds up to on the exchange. The count comes from how often your live strategies have been in a trade together, capped by what your balance can carry at Hyperliquid's $10 minimum order
- Probation strategies on Live Trades turn green when they are ready for full size and red when they have failed and going back to paper is recommended
- You can start probation for several strategies at once from the Pipeline page: select them and pick "Start probation". You type PROBATION once for the whole batch, and each strategy still goes through its own checks
- Linux: "./launcher.sh autostart on" starts Forven after every reboot (off unless you turn it on)
- Paper strategies that pass every other probation check get their held-back test run for them every hour, so they show as ready for probation without waiting for you. Starting probation itself stays manual
- A paper-only cross-sectional momentum book for research (no real orders)

Fixes:
- Probation limits keep working when a backtest's trade file is missing: Forven measures against the pinned backtest, or the fullest backtest run with the same settings, and marks a strategy amber ("Limits can't be checked") when there is none, instead of quietly checking nothing
- Held-back test quota is counted by strategy type, best paper records are tested first, and real paper fills can prove a strategy's edge covers costs
- Much smaller database and log growth, and a repeated warning prints once an hour instead of hundreds of thousands of times a day
- Fewer false alerts on Diagnostics and the trading desk, and you can dismiss items on the desk's attention list
- When a daemon step times out, the log names what actually held it up
- Funding and basis history downloads first, so a slow backfill no longer starves it
- macOS start script works with the built-in bash, the setup wizard says plainly that paper trading needs no exchange keys, and Coinbase history pages correctly

Safety:
- Shared coins is ON after this update for live trading on the main wallet. On first start Forven switches over by itself and tells you. Any live position you already hold is taken over: a "disaster stop" for the whole coin goes on Hyperliquid first, then that trade's own stop and target orders are cancelled and Forven runs them. If anything doesn't match the exchange, nothing changes and it tries again every 10 minutes
- Forven must be running for each strategy's stop and target to fire. If it is down, the one disaster stop per coin (0.5% beyond the furthest strategy stop) is the only order resting on the exchange. On Linux, turn on autostart
- If you use separate long and short accounts (Settings > Hyperliquid > "Separate long and short accounts"), shared coins stays OFF and nothing changes for you. To switch: close or wait out any open live positions, move the USDC from both sub-accounts back to your main wallet on Hyperliquid (Sub-Accounts page, Transfer), then turn "Separate long and short accounts" off. Forven switches on within a minute. You don't need the separate accounts any more: a long and a short on the same coin now net on one account
- To go back to one live strategy per coin, type ONE PER COIN on the Risk page under "Shared coins" (only while no live position is open)
