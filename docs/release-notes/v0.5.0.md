# Forven 0.5.0 — live strategies can share coins
#
# Hand-written notes for scripts/release.py (lines starting with # are ignored).
# Sections: New, Fixes, Safety; one "- " line per change, in plain words.
# This file replaces the AI-written notes for v0.5.0, so it covers every PR merged
# since v0.4.1 (#313, #314, #317-#323) plus the netting wording follow-up.

New:
- Live strategies can now share coins: any number of live strategies, long or short, can trade the same coin. Hyperliquid holds one position per coin per account, so the exchange shows the sum of their trades, and Forven runs each strategy's own stop and target
- This is on by default. On your first start after updating, Forven switches live trading over by itself and tells you. Any open live positions are taken over: each coin gets one wide "disaster" stop on the exchange first, then Forven runs each trade's own stop and target
- Live money is divided into slots (one slot is one full-size position), sized from your own balance. The Live Trades page shows free and used slots, each coin's net position and its disaster stop
- Using "Separate long and short accounts" (long and short sub-accounts)? Shared coins stay off for you until you switch, because they run on your main wallet only. To switch, with no live position open: move the USDC from both sub-accounts to your main wallet on Hyperliquid, then turn that setting off in Settings > Hyperliquid. Shared coins turn on within about 10 minutes. The Risk page panel explains this too
- Most installs should leave sub-accounts off: Hyperliquid only allows sub-accounts after $100k of trading volume, and they split your money in half while still allowing one strategy per coin per side
- Strong paper strategies now get their held-back test started for them, best paper record first, so they reach "Ready for probation" without you guessing which one to click
- The probation edge check can now pass on real paper fills: 10 or more matching paper trades on the home coin that cover costs by the required multiple (new setting next to the edge setting; 0 turns it off)
- Linux: ./launcher.sh autostart on starts Forven after every reboot (menu option 9). It is off until you turn it on
- A paper-only cross-sectional momentum book (XS-VolMom) runs daily alongside your strategies, with no effect on live trading
- Trading desk warnings and notes can be dismissed for 7 days

Fixes:
- Funding and basis history now download first in the bulk backfill, so strategies are no longer held at the live gate on "Funding data incomplete"
- The held-back test quota now counts by strategy type, so one crowded family no longer uses up everyone's tests, and the edge check no longer rounds 1.96x up to 2.0x and then fails it
- Much less noise: repeated daily execution-quality alerts, agent bug reports and stale notifications no longer fill Diagnostics, and "already has an open position" no longer counts as a refused entry
- The database and logs grow far more slowly: finished agent tasks, old checkpoints and oversized candle snapshots are cleaned up, and a warning repeated from the same line prints once an hour
- Data health and bot fills no longer show stale or doubled entries
- macOS startup works with the built-in bash, the setup wizard says paper trading needs no exchange keys, and Coinbase downloads page through the full range
- When the daemon loop stalls, the log now names what blocked it

Safety:
- With shared coins on, Forven runs each strategy's stops, so keep Forven running while live positions are open. The per-coin disaster stop on the exchange is the backstop if it is not
- If Forven's trades on a coin don't match the exchange, new entries on that coin pause and you are asked how to resolve it. Forven never trades by itself to fix a difference
- You can turn shared coins off on the Risk page by typing ONE PER COIN, once no live position is open
