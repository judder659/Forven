# Forven 0.4.2: live strategies can share coins
#
# Hand-written notes for scripts/release.py (lines starting with # are ignored).
# Sections: New, Fixes, Safety; one "- " line per change, in plain words.
# This file REPLACES the automatic notes for 0.4.2: add a line for every PR
# merged to main before the release runs.

New:
- Live strategies can now share coins: any number can trade the same coin (long or short) at once. Hyperliquid holds one net position per coin while Forven tracks each strategy's trade, stop, target and PnL separately (docs/live-netting.md)
- Live Trades shows shared-coin slots at the top: how many positions your balance can carry (from overlap history, capped by Hyperliquid's $10 minimum order), how many are in use, and each coin's net position
- Probation rows on Live Trades highlight green when ready for full size and red when failed (return to paper recommended); long lists collapse to surface strategies needing action first
- Bulk-start probation from Pipeline: select strategies, pick "Start probation", and confirm once with PROBATION (each still runs its own checks)
- Paper strategies that can no longer reach live (failed held-back test, edge below costs over 20+ paper trades, or losing over 10+ trades) auto-retire to the archive (Settings > Pipeline)
- Paper strategies passing all other probation checks get their held-back test run hourly; starting probation stays manual
- Linux: "./launcher.sh autostart on" starts Forven after reboot (off by default)
- Paper-only cross-sectional momentum book for research (no real orders)

Fixes:
- Removed the 5-strategy live cap, lifted the default probation cap from 10 to unlimited (auto-migrated for unchanged installs), and fixed probation settings in Settings > Pipeline so changes save and take effect
- Live Trades no longer shows stale coin-conflict or "all at once" margin warnings when shared coins is on
- Forge status and "Why" load much faster after restarts and show "Retrying gates…" instead of "Not assessed" while recovering
- Restarts on Linux and macOS stop cleanly without leaving an orphaned backend worker on old code
- The daemon caches active coins in the background instead of stalling every tick (fixing spurious timeouts), and timed-out steps log what held them up
- Probation limits still work when a backtest's trade file is missing (using the pinned or fullest matching backtest) and flag amber ("Limits can't be checked") when none exists
- Deep OI, long/short and taker history now downloads ~10 min after install (or next restart if never run) instead of after a month; funding/basis downloads first. The download runs in 20-minute chunks each hour and picks up where it stopped, so it no longer times out before reaching most coins
- Held-back test quota counts by strategy type, best paper records run first, and real paper fills can prove a strategy's edge covers costs
- Smaller database/log growth, repeated warnings log hourly, fewer false alerts on Diagnostics/desk (with dismissible desk attention items)
- Paper strategies no longer log "runtime type is not registered" after a restart: the strategy list now waits for all strategy types (built-in and your own) to load instead of reading a half-loaded list
- macOS start script works with built-in bash, setup wizard notes paper mode needs no keys, and Coinbase history paginates properly
- Propr page: the challenge scorecard no longer fails with "signal timed out"; it shows the last copy at once and refreshes in the background

Safety:
- Shared coins is ON after this update for live trading on the main wallet. On first start Forven switches over and notifies you. Open live positions are taken over safely: a per-coin "disaster stop" is placed on Hyperliquid first, then per-trade stop/target orders are cancelled and managed by Forven. Any mismatch leaves nothing changed and retries every 10 minutes
- Forven must be running for per-strategy stops and targets to fire; if down, only the per-coin disaster stop (0.5% beyond the furthest stop) rests on the exchange. On Linux, enable autostart
- With separate long/short accounts (Settings > Hyperliquid > "Separate long and short accounts"), shared coins stays OFF. To switch: let open live positions close, transfer USDC from both sub-accounts back to your main wallet on Hyperliquid (Sub-Accounts > Transfer), then turn "Separate long and short accounts" off. Shared coins enables within a minute
- To return to one live strategy per coin, type ONE PER COIN on the Risk page under "Shared coins" (only with no live positions open)
- Propr challenge mirror: past 80% of the drawdown allowance it no longer stops for good (with nothing open, equity could never recover). It keeps trading at half risk, never with more open loss-at-stop than the room left before a hard stop at 95%, and returns to normal size under 80%
